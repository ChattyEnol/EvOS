# **Evoncil OS**

编译器指定为 `clang`，由于是裸机编程，因此不需要标准 C 库。

建议使用 LLVM 在 GitHub 上的官方仓库。

## **代码说明**

### **引导程序**

基于 EDK II 头文件开发，引导程序为 EFI 程序、运行在 UEFI 上。没有 Microsoft 签名，因此需要关闭安全启动。

引导程序有少量 LibC 函数实现，使用了 EDK II LibC 头文件。

### **内核**

内核是裸机程序，链接为一个静态库后供 EFI 跳板链接，最终输出一个 EFI 程序。

## **平台与运行说明**

目前仅写了 `X64` 平台实现，`ARM64` 留了个占位符，但我暂时不打算实现。

构建结果为一个根目录下的 `VHDX` 文件，可直接放 Hyper-V 里运行、或使用 Rufus 等工具制作启动盘在物理机上运行。
